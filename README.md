# MiniMart 🛒

MiniMart is an e-commerce shopping web application where users can browse products, add items to cart, and proceed through the checkout process.

## 🚀 Features

- User Login Page
- Product Listing
- Add to Cart Functionality
- Cart Management
- Checkout Page
- Responsive Design

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
